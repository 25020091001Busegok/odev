# Rectangle Ödevi

Bu projede Java kullanılarak basit bir `Rectangle` sınıfı oluşturulmuştur.

## Projenin Amacı

Dikdörtgenin genişlik ve yükseklik bilgilerini tutmak, alanını ve çevresini hesaplamak.

## Rectangle Sınıfı

Sınıf içerisinde:

- `width` değişkeni
- `height` değişkeni
- Parametresiz constructor
- Parametreli constructor
- `getArea()` metodu
- `getPerimeter()` metodu

bulunmaktadır.

## Kullanılan Değerler

Programda iki farklı dikdörtgen nesnesi oluşturulmuştur:

- 1. dikdörtgen: width = 4, height = 40
- 2. dikdörtgen: width = 3.5, height = 35.9

## Hesaplamalar

Alan hesabı:

`width * height`

Çevre hesabı:

`2 * (width + height)`

## Dosyalar

- `Rectangle.java` → Rectangle sınıfını içerir.
- `Odev.java` → Programın çalıştırıldığı ve nesnelerin oluşturulduğu ana dosyadır.
